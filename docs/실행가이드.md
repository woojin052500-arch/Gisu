# 실행 가이드 — 다음기수 띄우기

파일이 두 개입니다. 목적이 다르니 헷갈리지 마세요.

| 파일 | 누가 보나 | 목적 |
|---|---|---|
| **landing.html** | 프로그램 **운영자** | 제품 소개 + 사전 등록(전화번호) 받기 |
| **apply.html** | 프로그램 **신청자** | 실제로 신청 받기 (운영자에게 쥐여줄 도구) |

먼저 landing.html로 수요를 확인하고, 관심을 보인 운영자에게 apply.html을 직접 돌려주는 순서입니다.

---

## 0단계 — 랜딩 페이지 띄우기 (5분)

1. `landing.html`을 편집기로 엽니다.
2. 아래쪽 스크립트에서 이 한 줄을 찾습니다.

   ```js
   const WEBHOOK = '';   // 예: 'https://script.google.com/macros/s/AKfy.../exec'
   ```

3. 따옴표 안에 1단계에서 받은 Apps Script URL을 붙여넣고 저장합니다.
4. `landing.html`을 [Netlify Drop](https://app.netlify.com/drop)에 끌어다 놓습니다. 주소가 나옵니다.
5. 그 주소를 커뮤니티·오픈채팅·인스타에 뿌립니다.

**사전 등록 현황**은 주소 끝에 `#stats`를 붙이면 봅니다. (예: `https://xxx.netlify.app/landing.html#stats`)
방문자에게는 보이지 않습니다. 구글 시트의 `사전등록` 탭에도 그대로 쌓입니다.

> 사전 등록자 수는 10명을 넘겨야 랜딩에 "이미 N명이 등록했습니다"로 노출됩니다. 숫자가 적을 때 보여주면 오히려 등록을 막기 때문입니다.

# 신청 폼(apply.html) 띄우기

총 소요 15분. 순서를 바꾸면 막히니 위에서부터 그대로 하세요.

---

## 1단계 — 신청서 받을 곳 만들기 (5분)

1. 구글 스프레드시트를 새로 만듭니다. 이름은 아무거나 상관없습니다.
2. 상단 메뉴에서 **확장 프로그램 → Apps Script**를 엽니다.
3. 기본으로 들어있는 `function myFunction() {}` 을 지우고, **google-apps-script.gs** 파일 내용을 전부 붙여넣습니다.
4. 저장(Ctrl+S) 후 오른쪽 위 **배포 → 새 배포**를 누릅니다.
5. 톱니바퀴 아이콘 → **웹 앱**을 선택하고 아래처럼 설정합니다.

   | 항목 | 값 |
   |---|---|
   | 설명 | 아무거나 |
   | 실행 계정 | **나** |
   | 액세스 권한 | **모든 사용자** |

   > 액세스 권한이 "모든 사용자"가 아니면 신청서가 들어오지 않습니다. 여기서 막히는 경우가 대부분입니다.

6. 배포를 누르면 권한 승인 창이 뜹니다. 계정 선택 → "고급" → "안전하지 않은 페이지로 이동" → 허용.
   (본인이 만든 스크립트라 나오는 경고입니다.)
7. 마지막에 나오는 **`/exec`로 끝나는 URL**을 복사해 둡니다. 이게 웹훅 URL입니다.

---

## 2단계 — 신청 페이지 인터넷에 올리기 (3분)

`apply.html`을 그냥 더블클릭해서 열면 주소가 `file:///...`이라 남에게 줄 수 없습니다. 반드시 올려야 합니다.

가장 빠른 방법은 **Netlify Drop**입니다. 가입 없이 파일을 끌어다 놓으면 끝입니다.

1. https://app.netlify.com/drop 접속
2. `apply.html` 파일을 화면에 끌어다 놓습니다
3. 몇 초 뒤 `https://xxxx-xxxx.netlify.app` 형태의 주소가 나옵니다
4. 그 주소 뒤에 `/apply.html`을 붙인 것이 운영자 화면입니다

> 나중에 수정한 파일을 다시 끌어다 놓으면 그대로 갱신됩니다.
> GitHub Pages나 Vercel을 이미 쓰고 있다면 그쪽에 올려도 똑같습니다.

---

## 3단계 — 프로그램 정보 입력하고 링크 뽑기 (5분)

1. 2단계에서 나온 주소를 브라우저로 엽니다. 운영자 화면이 뜹니다.
2. 1~4번 항목을 채웁니다. 참가비와 계좌는 꼭 넣으세요 — 접수 완료 화면의 입금 안내가 여기서 나옵니다.
3. **5번 칸에 1단계에서 복사한 웹훅 URL**을 붙여넣습니다.
4. 6번에서 신청자 수 공개 여부와 공개 시작 인원을 정합니다. 기본값 5명을 권합니다.
5. **신청 링크 만들기**를 누르면 링크가 나옵니다. 이걸 카톡·인스타에 뿌립니다.

> 입력값은 브라우저에 자동 저장됩니다. 다음 기수를 열 때 같은 주소로 들어오면 그대로 남아 있어서 숫자만 고치면 됩니다.

---

## 4단계 — 배포 전에 반드시 테스트 (2분)

1. 만든 링크를 **본인 휴대폰**으로 열어봅니다. 카톡으로 자기 자신에게 보내서 열면 실제 신청자와 같은 조건이 됩니다.
2. 본인 이름으로 한 건 신청해 봅니다.
3. 구글 스프레드시트에 '신청자' 시트가 생기고 줄이 추가됐는지 확인합니다.
4. 메일함에 신규 신청 알림이 왔는지 확인합니다.
5. 운영자 화면에서 **현황 조회**를 눌러 1명으로 뜨는지 확인합니다.
6. 확인이 끝나면 **테스트로 넣은 줄을 시트에서 지웁니다.** 안 지우면 신청자 수가 1명부터 시작합니다.

---

## 운영 중에 하는 일

- **입금이 들어오면** 시트의 `입금확인` 열에 아무 글자나(예: O, 날짜) 적습니다. 현황 조회에 입금 확인 인원으로 집계됩니다.
- **신청자 수 확인**은 운영자 화면의 현황 조회 버튼입니다. 정원 대비 남은 자리와 미입금 인원이 같이 나옵니다.
- **모집 마감일**이 지나면 신청 페이지가 자동으로 마감 상태로 바뀝니다.
- **정원이 차면** 신청 버튼이 '대기 명단으로 신청하기'로 바뀝니다. 신청은 계속 받되 대기로 관리하면 됩니다.

---

## 자주 막히는 곳

| 증상 | 원인과 해결 |
|---|---|
| 신청해도 시트에 안 들어옴 | 배포 시 액세스 권한이 "모든 사용자"가 아님. 배포 관리에서 수정 후 **새 배포** |
| 현황 조회가 실패함 | 위와 동일. 또는 URL이 `/exec`가 아니라 `/dev`로 끝남 |
| 코드를 고쳤는데 반영이 안 됨 | Apps Script는 저장만으로 반영되지 않음. **배포 → 새 배포**를 다시 해야 함 |
| 링크가 너무 김 | 정상입니다. 서버 없이 링크 안에 정보를 담고 있어서 그렇습니다. 신경 쓰이면 단축 URL을 쓰세요 |
| 신청자 수가 안 보임 | 설정한 공개 시작 인원(기본 5명)을 아직 못 넘겼습니다. 의도된 동작입니다 |

## 다음에 붙일 것

지금 구조는 검증용입니다. 실제 신청자 20명을 한 번 통과시킨 뒤에 아래를 판단하세요.

1. **입금 대조 자동화** — 은행 알림을 파싱해 시트의 입금확인을 자동으로 채움
2. **결제 연동** — 포트원/토스페이먼츠. 계좌이체를 아예 없앰
3. **기수 복제** — 지난 기수 설정과 참가자를 승계. 유료 플랜의 과금 지점
